### Video V98: Cryptanalytic Attacks Part I (Known Plaintext, Brute Force)

```mermaid
graph TD
    subgraph Goal
        Goal[Compromise cryptographic system<br/>Discover the encryption KEY]
    end

    subgraph Attack Vectors
        Vectors[Plaintext | Ciphertext | KEY 🎯 | Algorithm/Cipher]
    end

    subgraph Known Plaintext Attacks
        BF[Brute Force Attack<br/>Try every possible combination<br/>Eventually successful with time/resources]
        LC[Linear Cryptanalysis<br/>Linear math equations<br/>Statistical analysis of cipher]
        MITM[Meet-in-the-Middle Attack<br/>Targets ciphers with multiple rounds<br/>Encrypt/decrypt with every key to find match]
    end

    subgraph Chosen Plaintext Attacks
        CPA[Select specific portion of plaintext<br/>to encrypt and analyze<br/>Reduces analysis time]
    end

    subgraph Differential Cryptanalysis
        DC[Analyze differences in ciphertext outputs<br/>Based on changes in input<br/>Bits of key or plaintext<br/>Best used with Chosen Plaintext]
    end

    Goal --> Vectors
    Vectors --> BF
    BF --> LC
    LC --> MITM
    MITM --> CPA
    CPA --> DC
```

### Video V99: Cryptanalytic Attacks Part II (Ciphertext-Only, Hash Attacks)

```mermaid
graph TD
    subgraph Ciphertext-Only Attacks
        COA[Only ciphertext available<br/>Key, plaintext, cipher UNKNOWN<br/>Most common scenario - sniffing traffic<br/>Difficult and lengthy to execute]
        
        subgraph Techniques
            RKA[Related-Key Attack<br/>Compare same ciphertext<br/>Generated by mathematically related keys]
            CCA[Chosen Ciphertext Attack<br/>Focus on specific ciphertext portion<br/>Analyze decryption process]
            FA[Frequency Analysis<br/>Analyze character/group frequency<br/>Identify cipher algorithm]
        end
    end

    subgraph Hash-Based Attacks
        PTH[Pass-the-Hash<br/>Target: Windows LANMAN, NTLM<br/>Use stolen hash for authentication<br/>No plaintext password needed]
        
        Kero[Kerberoasting<br/>Target: Windows Kerberos<br/>Harvest Kerberos password hashes<br/>Targets Golden/Silver Tickets]
        
        Birthday[Birthday Attack<br/>Target: Hash collisions<br/>Based on Birthday Paradox<br/>Exploit collision likelihood]
        
        Rainbow[Rainbow Table Attack<br/>Precomputed hash database<br/>Compare stolen hashes against<br/>precomputed table of common passwords]
    end

    COA --> RKA
    COA --> CCA
    COA --> FA
    FA --> PTH
    PTH --> Kero
    Kero --> Birthday
    Birthday --> Rainbow
```

### Video V100: Cryptanalytic Attacks Part III (Implementation Attacks)

```mermaid
graph TD
    subgraph Attacking the Cryptosystem
        FI[Fault Injection<br/>Inject errors/invalid data<br/>Observe how system responds]
```
