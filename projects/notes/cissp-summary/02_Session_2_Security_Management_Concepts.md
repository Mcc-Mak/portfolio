## Video V6: Code of Ethics (ISC2 Code & Canons)

**Objective:** To explain the ISC2 Code of Ethics and its application.

### I. Definition of Ethics
- A set of moral principles guiding professional conduct and ethical decision-making.

### II. Core Requirements
- **Adherence:** All ISC2 certification holders must adhere.
- **Violations:** Subject to peer review; may result in revocation.
- **Reporting:** Members must report violations by others.

### III. The Four Canons (The "PAPA" Mnemonic)
| Canon | Meaning | In Practice |
| :--- | :--- | :--- |
| **P - Protect** | Society, common good, infrastructure | Safeguard information systems; consider societal impact |
| **A - Act** | Honorably, honestly, justly, legally | Maintain integrity; be transparent; lead by example |
| **P - Provide** | Diligent and competent service | Stay current; avoid conflicts; deliver quality work |
| **A - Advance** | The profession | Share knowledge; mentor others; foster learning |

## Video V7: Information Security Concepts (CIA Triad)

**Objective:** To define confidentiality, integrity, availability, authenticity, and non-repudiation.

### I. The CIA Triad
| Concept | Definition | Key Protection |
| :--- | :--- | :--- |
| **Confidentiality** | No disclosure to unauthorized persons | Encryption, access controls |
| **Integrity** | No unauthorized alteration | Hashing, change management |
| **Availability** | Accessible when needed | Redundancy, DoS protection |

### II. Authenticity & Non-Repudiation
- **Authenticity:** Verifying that data/actions come from a legitimate source (e.g., login credentials).
- **Non-Repudiation:** Proving an action originated from a specific subject; cannot be disputed (e.g., digital signatures).

## Video V8: Aligning Security and the Organization (Governance)

**Objective:** To explain how security must support business objectives.

### I. Core Principle
- Security's purpose is to **enable the business**, not hinder it.
- **Governance** defines rules; **compliance** verifies them.

### II. The "Top-Down" Approach
| Level | Responsibility |
| :--- | :--- |
| **Senior Management** | Defines policies; ultimate accountability |
| **Middle Management** | Creates security artifacts (procedures, standards) |
| **Security Professionals** | Implementers of policy |

### III. The Three Types of Security Plans
| Plan Type | Timeframe | Focus |
| :--- | :--- | :--- |
| **Strategic** | 3-5 years | Long-term vision and goals |
| **Tactical** | ~1 year | Specific projects (e.g., cloud migration) |
| **Operational** | 1-3 months | Short-term tasks and objectives |

## Video V9: Organizational Roles and Responsibilities

**Objective:** To define the four main role categories.

### I. The Four Main Role Categories
| Category | Key Roles | Responsibility |
| :--- | :--- | :--- |
| **Executive** | CEO, CFO, CIO, CISO | Mission, vision, strategy; ultimate accountability |
| **Security** | Manager, Officer, Analyst, Engineer | Develop, implement, and manage security program |
| **Data** | Owner, Custodian, Steward | Classification, protection, and expertise for data |
| **System** | Administrator, Auditor, User | Implement, maintain, and audit systems |

### II. Critical Data Roles (For the Exam)
| Role | Responsibility |
| :--- | :--- |
| **Data Owner** | Classifies data; accountable for protection |
| **Data Custodian** | Implements protection (keyboard-level execution) |
| **Data Steward** | Provides subject matter expertise (e.g., PII, GDPR) |

## Video V10: Security Awareness, Education, and Training

**Objective:** To explain how to establish and maintain a security awareness program.

### I. The Three Pillars
| Pillar | Focus | Example |
| :--- | :--- | :--- |
| **Awareness** | The "what" | Posters, emails, newsletters |
| **Training** | The "how" | Teaching secure remote access, incident response |
| **Education** | The "why" & beyond | Certification programs, degrees |

### II. Encouraging Participation
- **Security Champions:** Enthusiastic "cheerleaders" to promote the program.
- **Gamification:** Points, badges, levels, challenges to make training fun and rewarding.

### III. Evaluation & Continuous Improvement
- Monitor participation rates and behavior change (e.g., decrease in successful phishing attacks).
- Update content and delivery methods based on feedback and emerging threats.

## Video V11: Social Engineering

**Objective:** To explain social engineering techniques and defenses.

### I. Core Techniques
| Technique | Description |
| :--- | :--- |
| **Pretexting** | Creating a fictitious story to manipulate trust |
| **Quid Pro Quo** | "Something for something" to create obligation |

### II. Phishing Variants
| Variant | Target |
| :--- | :--- |
| **Spear Phishing** | Specific individual or small group |
| **Whaling** | High-value targets (C-suite executives) |
| **Vishing** | Voice/phone calls |
| **Smishing** | SMS/text messages |
| **SPIM** | Instant messaging |

### III. Physical Attacks
- **Shoulder Surfing:** Watching keystrokes or screens.
- **Dumpster Diving:** Searching trash for sensitive documents.
- **Tailgating:** Following an authorized user without their knowledge.
- **Piggybacking:** Tricking a user into knowingly allowing access.

### IV. Defenses
- Security awareness training to identify and report attacks.
- Require identification and authentication (badges, vendor verification).

## Video V12: Personnel Security Policies (Lifecycle)

**Objective:** To explain the personnel security lifecycle from hiring to termination.

### I. Key Control Principles
| Principle | Description |
| :--- | :--- |
| **Separation of Duties** | Divide critical functions among multiple individuals |
| **Least Privilege** | Grant only necessary privileges for the job |
| **Need to Know** | Restrict data access to job duties only |

### II. The Personnel Lifecycle Phases
| Phase | Key Activities |
| :--- | :--- |
| **Candidate Screening** | Job description, background checks, interviews |
| **Hiring & Agreements** | NDA, Non-Compete, Acceptable Use Policy (AUP) |
| **Onboarding** | Training, acknowledgment, authorization |
| **Offboarding (Termination)** | Immediate access revocation, property collection, password changes |

## Video V13: Personnel Safety and Security

**Objective:** To explain safety measures for travel, duress, and emergencies.

### I. Personnel Travel
- Ensure endpoint security (firewalls, anti-malware, VPN).
- Account for personnel during official business travel.

### II. Duress Situations
- **Duress Code Words:** Pre-agreed words to signal a problem without alerting an attacker.
- **Duress PINs / Alarm Codes:** Special codes that trigger silent alarms and dispatch security.

### III. Emergency Management
- Procedures for contacting the organization during emergencies.
- Ingress/egress procedures and designated evacuation areas.

### IV. Training and Awareness
- Specialized training for higher-risk roles.
- Train on fire alarms, duress codes, and recall procedures.
