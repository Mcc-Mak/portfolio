### 🔹 Question 209 (7.6.3)
Mitigating an attack involves two logically separate tasks: eradication and _____.
<br/>A. Identification
<br/>B. Containment
<br/>C. Remediation
<br/>D. Recovery

**✅ Correct Answer: D. Recovery**

```text
Feedback: According to the NIST Incident Response Lifecycle (SP 800-61), the four phases are:
Preparation, Detection & Analysis, Containment/Eradication/Recovery, and Post-Incident Activity.
Within the third phase, the two logically separate tasks are:
- Eradication: removing the threat artifacts (malware, backdoors, persistence mechanisms)
- Recovery: restoring normal operations (system restoration, data restoration, service resumption)

Identification (A) occurs in the Detection & Analysis phase. Containment (B) precedes eradication.
Remediation (C) is often used interchangeably with eradication but is not the standard paired term.
The standard pairing in NIST guidance is Eradication and Recovery.
```

### 🔹 Question 213 (7.10.1)
What is typically used to validate the integrity of a backup?
<br/>A. Measuring the size of the original data and comparing it to the size of the backup
<br/>B. Some form of integrity check
<br/>C. An algorithm developed by the backup software manufacturer
<br/>D. Restoration of the backup to a different location and then an integrity check

**✅ Correct Answer: D. Restoration of the backup to a different location and then an integrity check**

```text
Feedback: While checksums and hash verification (B) provide a basic integrity check,

to a different location and then verifying the restored data (e.g., hash comparison,
application testing). This confirms not only that the data is intact but also that the
restoration process works. Option A (size comparison) is insufficient—size can match
while data is corrupted. Option C is too vague and manufacturer-specific. Option D
represents industry best practice for production environments.
```
