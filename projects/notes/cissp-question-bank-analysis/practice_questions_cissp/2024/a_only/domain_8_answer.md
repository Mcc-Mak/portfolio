## Question 233 (8.5.1)
**Correct Answer:** B. A deadlock

**Feedback:** A deadlock occurs when two more processes each hold open or have placed an exclusive use lock on some elements of a set of resources that the other needs to complete its own processing thus preventing either from completing the action.

## Question 240 (8.5.3)
**Correct Answer:** A. Transaction persistence

**Feedback:** Transaction persistence requires that the state of the database is the same as it was prior to the transaction after a transaction against the database has occurred, except for those data elements specifically affected (created, modified, or deleted) by the transaction itself.
