### 🔹 Question 83 (2.6.4)
Which of these statements accurately describes an aspect of link encryption and
its potential impact on data security in the following scenario? A Network
Security Specialist at an international corporation frequently transmits sensitive
corporate data across various global locations. Given the nature of the data and
the diverse transmission routes, the company is exploring enhanced encryption
methods to secure its data in transit. The corporation is evaluating the use of
link encryption for its data communications across satellite links, telephone
circuits, and T-1 lines.
<br/>A. Link encryption encrypts only the content of the data packet, leaving the
     routing information unencrypted, thus making it susceptible to traffic
     analysis attacks.
<br/>B. With link encryption, the data packet, including the routing information,
     is encrypted at the source and remains encrypted until it reaches the final
     destination, without decryption at intermediate points.
<br/>C. Link encryption encrypts both the data and the routing information in the
     packet, requiring decryption and re-encryption at each node in the
     communication path, potentially exposing data at these points.
<br/>D. Link encryption is less effective in providing traffic confidentiality
     compared to end-to-end encryption, as it does not conceal the addressing
     information from potential observers.

**✅ Correct Answer: C. Link encryption encrypts both the data and the routing
information in the packet, requiring decryption and re-encryption at each node
in the communication path, potentially exposing data at these points.**

```text
Feedback: Link encryption encrypts all data within a packet, including the
routing information. At each node along the communication path, such as
satellites or routers, the packet is decrypted and then re-encrypted. This
process ensures traffic confidentiality but also potentially exposes data at
these intermediate points if a node is compromised.
```

### 🔹 Question 71 (2.4.6)
Which of the following should be considered a source of data remanence?
<br/>A. Central Processing Unit (CPU) registers
<br/>B. Random Access Memory (RAM)
<br/>C. Solid State Drives (SSDs)
<br/>D. All the above

**✅ Correct Answer: D. All the above**

```text
Feedback: Data remanence refers to residual data remaining on storage media or memory after deletion or erasure. All listed components can exhibit data remanence: CPU registers may retain residual charge/data briefly after power loss (though volatile, advanced techniques can recover). RAM (especially when cold-boot attacks are possible) can retain data for seconds to minutes after power loss. SSDs present significant remanence challenges due to wear leveling, over-provisioning, and the inability to guarantee overwriting of specific blocks. Therefore, all are sources of potential data remanence.
```

### 🔹 Question 72 (2.4.6)
Which of these actions is MOST effective in the following scenario? The Information Security Officer at a law firm regularly handles sensitive client information. The Information Security Officer must mitigate the risks associated with data remanence.
<br/>A. Regularly updating antivirus software on all firm computers
<br/>B. Implementing a policy for the frequent change of user passwords
<br/>C. Using data wiping techniques that overwrite the storage media multiple times
<br/>D. Restricting access to sensitive data based on user roles and privileges

**✅ Correct Answer: C. Using data wiping techniques that overwrite the storage media multiple times**

```text
Feedback: Data remanence is specifically about residual data remaining after deletion or erasure. The most effective mitigation is secure data wiping techniques that overwrite storage media multiple times (e.g., DoD 5220.22-M, Gutmann method, or cryptographic erasure). Antivirus (A) addresses malware, not remanence. Password policies (B) address authentication security. Access controls (D) address authorization, not data remanence after decommissioning or disposal.
```

### 🔹 Question 84 (2.6.4)
Which form of encryption does a Virtual Private Network (VPN) typically use to protect data in transmission, ensuring the confidentiality and integrity of the data from the sender to the receiver?
<br/>A. Symmetric encryption, where the same key is used for both encryption and decryption of the data
<br/>B. Asymmetric encryption, where two different keys are used, one for encryption and another for decryption
<br/>C. Link encryption, which is applied by service providers along the communication path
<br/>D. End-to-end encryption, where the data is encrypted at the start of the transmission by the sender and is decrypted by the receiver

**✅ Correct Answer: D. End-to-end encryption, where the data is encrypted at the start of the transmission by the sender and is decrypted by the receiver**

```text
Feedback: A VPN creates an encrypted tunnel between the sender and receiver (VPN client and VPN gateway/server). The data is encrypted at the originating device and decrypted only at the destination VPN endpoint, providing end-to-end encryption across the tunnel. While VPNs use symmetric encryption (A) for the data channel after key exchange, the question asks for the form of encryption—end-to-end describes the encryption model. Asymmetric encryption (B) is used for key exchange, not the bulk data encryption. Link encryption (C) is provided by service providers, not characteristic of typical VPN implementations.
```
