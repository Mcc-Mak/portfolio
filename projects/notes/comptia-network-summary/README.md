# CompTIA Network+ (N10-009) Course Summaries

This repository contains a structured summary of the complete CompTIA Network+ (N10-009) certification course. The content is organized by session and video number, providing a comprehensive overview of networking concepts, implementation, operations, security, and troubleshooting.

| Session | Video(s) | Summary |
| :--- | :--- | :--- |
| **Session 1** | V1, V3 | **Course Introduction & Exam Tips** - Overview of exam domains (23% Networking Concepts, 20% Implementation, 19% Operations, 14% Security, 24% Troubleshooting). Details on exam logistics (90 minutes, ~90 questions, 720/900 passing score), instructor background, and student resources. Key exam tips: skip simulations initially, guess when unsure, use a brain dump sheet, and set a target study date (30-60 days). |
| **Session 2** | V4-V11 | **Network Fundamentals** - Covers core components (clients, servers, switches, routers), resource models (Client-Server vs. Peer-to-Peer), network geography (PAN, LAN, CAN, MAN, WAN), and physical/logical topologies (star, mesh, bus, ring). Includes datacenter architectures (three-tier, spine-leaf) and real-world examples of converged networks. |
| **Session 3** | V12-V21 | **OSI Model** - Deep dive into all 7 layers (Physical to Application). Includes data naming (bits, frames, packets, segments), encapsulation vs. decapsulation, and key details for each layer (e.g., MAC addresses at L2, routing at L3, TCP/UDP at L4). Features a Wireshark demonstration for packet analysis. |
| **Session 4** | V22-V33 | **Ports and Protocols** - Comprehensive review of port ranges (well-known, registered, dynamic). Details common protocols: TCP/UDP/ICMP, web (HTTP/HTTPS), email (SMTP,POP3,IMAP), file transfer (FTP,SFTP,TFTP), remote access (SSH,Telnet,RDP), and network services (DNS,DHCP,SNMP,Syslog). Includes an Nmap scanning demonstration. |
| **Session 5** | V34-V40 | **Media and Cabling** - Examines copper (UTP/STP, Cat specifications, coax, twinaxial) and fiber (single-mode vs. multi-mode) media. Details connectors (RJ45, BNC, SC, LC, ST), wiring standards (568A/568B, straight-through vs. crossover), transceivers (SFP, QSFP), and cable testing tools. |
| **Session 6** | V41-V47 | **Distribution Systems** - Focuses on structured cabling (MDF, IDF, patch panels), power distribution (UPS, PDU, generators), HVAC requirements, and fire suppression (wet pipe vs. clean agent). Includes demonstrations on wiring, testing with a toner probe, and power management. |
| **Session 7** | V48-V57 | **Wireless Networks** - Covers network types (infrastructure, ad hoc, mesh), antennas (omnidirectional, Yagi), frequencies (2.4, 5, 6 GHz), and 802.11 standards (a/b/g/n/ac/ax). Details wireless security (WEP, WPA, WPA2, WPA3, WPS), configuration settings, and attacks (e.g., WEP cracking with Aircrack-ng). Discusses captive portals and site surveys. |
| **Session 8** | V58-V67 | **Ethernet Switching** - Explains CSMA/CD, collision/broadcast domains, and the evolution from hubs to switches. Details VLANs (tagging, trunking, native VLAN), STP (preventing loops), NAC (port security, 802.1X), and MTU considerations. Includes VLAN configuration demonstrations. |
| **Session 9** | V68-V79 | **IP Addressing** - Covers IPv4 (classes, public/private, APIPA, loopback), subnetting (CIDR, VLSM, formulas, and "by-hand" shortcut), and IPv6 (128-bit addressing, shorthand, types, SLAAC). Discusses IPv4/IPv6 compatibility (dual stack, tunneling, NAT64) and address assignment (static, DHCP). |
| **Session 10** | V80-V89 | **Routing** - Discusses routing tables, static vs. dynamic routes, and protocols (RIP, OSPF, EIGRP, BGP). Explains route selection (administrative distance, metrics), NAT/PAT, FHRP (HSRP, VRRP, GLBP), multicast routing (IGMP, PIM), and GRE tunnels. Includes a Cisco Packet Tracer demonstration. |
| **Session 11** | V90-V101 | **Network Services** - Details DHCP (DORA process, relays, scope exhaustion), DNS (record types, hierarchy, security with DNSSEC/DoH/DoT), NTP (stratum levels), and QoS (classification, queuing, shaping). Includes demonstrations on DHCP and DNS resolution. |
| **Session 12** | V102-V111 | **Wide Area Networks (WANs)** - Reviews WAN connection types: Fiber (FTTx), Cable (DOCSIS), DSL (ADSL, VDSL), Satellite (LEO vs. GEO), Cellular (4G/5G, GSM/CDMA), Microwave, Leased Lines, and MPLS (label switching). Discusses the modern "80/20" traffic rule shift to the cloud. |
| **Session 13** | V112-V123 | **Cloud and Datacenter** - Explores cloud characteristics (elasticity, metered utilization), service models (IaaS, PaaS, SaaS), and deployment models (public, private, hybrid). Discusses virtualization (NFV, SDN, SD-WAN, VXLAN), cloud security (VPCs, Direct Connect, VPN), and SASE/SSE frameworks. |
| **Session 14** | V124-V132 | **Network Security Fundamentals** - Covers the CIA Triad, threats vs. vulnerabilities, risk management, and compliance (PCI DSS, GDPR). Details device hardening (disable services, EOL/EOS), physical security (biometrics, mantrap), and active defense (honeypots, attribution). |
| **Session 15** | V133-V144 | **Network Attacks** - Comprehensive list of attacks: DoS/DDoS (SYN flood, Smurf), MAC flooding, ARP spoofing/poisoning, VLAN hopping, DNS attacks, on-path attacks, and social engineering (phishing, tailgating). Also covers malware types (viruses, worms, Trojans, ransomware, rootkits) with live demonstrations (WEP cracking, RATs). |
| **Session 16** | V145-V155 | **Logical Security** - Explains IAM, MFA (factors: knowledge, possession, inherence), and authentication methods (LDAP, Kerberos, SSO, RADIUS, TACACS+). Discusses encryption (symmetric/asymmetric, data states), IPSec (AH/ESP, transport/tunnel), PKI, digital certificates (X.509, CAs, CRLs), and key management. |
| **Session 17** | V156-V169 | **Network Segmentation & Security** - Details firewalls (packet filtering, stateful, NGFW, UTM), ACLs, and zones (trusted, untrusted, screened subnet). Covers IoT/SCADA security, BYOD vs. CYOD, Zero Trust Architecture, VPNs (site-to-site, client-to-site, split/full tunnel), and remote access (SSH, RDP, VNC). |
| **Session 18** | V170-V180 | **Network Monitoring** - Reviews IDS/IPS (signature/anomaly-based), SNMP (v1/v2c/v3, traps, MIBs), and network sensors (temperature, CPU, memory). Discusses packet captures (PCAPs), flow analysis (NetFlow, Zeek), log aggregation (Syslog), SIEMs, and performance metrics (latency, jitter, throughput). |
| **Session 19** | V181-V190 | **Orchestration and Automation** - Introduces Infrastructure as Code (IaC), benefits of automation (efficiency, consistency, workforce multiplier), and tools (playbooks, runbooks, SOAR). Discusses API integrations (REST/SOAP), source control (Git commands), and avoiding "snowflake" systems. |
| **Session 20** | V191-V199 | **Documentation and Processes** - Covers the documentation hierarchy (policies, standards, guidelines, procedures). Details asset management (inventory, lifecycle, licensing), IPAM, agreements (NDA, MOU, SLA), change management (CAB), configuration management (baselines), and patch management (testing rings). |
| **Session 21** | V200-V205 | **Disaster Recovery** - Explains high availability (active-active, load balancers, CDNs), redundancy design (power, hardware, paths), and DR metrics (MTBF, MTTR, RPO, RTO). Compares recovery sites (hot, warm, cold, mobile, virtual) and training methods (tabletop, penetration testing, red/blue teams). |
| **Session 22** | V206-V213 | **Troubleshooting Methodology** - Details the official CompTIA 7-step process: 1) Identify problem, 2) Establish theory, 3) Test theory, 4) Plan action, 5) Implement/escalate, 6) Verify functionality, 7) Document findings. Includes a walkthrough example and tips for avoiding common pitfalls. |
| **Session 23** | V214-V226 | **Troubleshooting Tools** - Comprehensive guide to hardware tools (cable tester, TDR/OTDR, toner probe, loopback adapter) and software/CLI tools (ipconfig, ping, traceroute, netstat, nslookup, nmap, tcpdump). Includes network device commands (show interfaces, show route, show mac-address-table) and discovery protocols (LLDP, CDP). |
| **Session 24** | V227-V234 | **Troubleshooting Physical Networks** - Addresses cable limitations (Cat specifications, distance), signal issues (attenuation, interference, decibel loss), and specific problems for copper (opens, shorts, bad pinouts) and fiber (dirty connectors, TX/RX reversal, transceiver mismatch). Also covers interface errors (CRC, runts, giants) and PoE (power budget, standard mismatch). |
| **Session 25** | V235-V241 | **Troubleshooting Wireless Issues** - Diagnoses coverage (RSSI, EIRP), interference (channel overlap, multipath), client disassociation (idle timeouts, de-auth attacks), and configuration errors (wrong SSID, encryption mismatch). Includes captive portal troubleshooting and optimizing AP placement/association times. |
| **Session 26** | V242-V250 | **Troubleshooting Network Services** - Solves issues with duplicate addresses (MAC/IP conflicts), DHCP (rogue servers, scope exhaustion), routing (asymmetrical routes, missing routes), switching/routing loops (STP, split-horizon), firewalls (ACL order), VLANs (routing between them), and DNS/NTP. |
| **Session 27** | V251-V256 | **Troubleshooting Performance Issues** - Diagnoses collisions (CSMA/CD), broadcast storms, VoIP problems (latency, jitter), and packet loss. Addresses high CPU/bandwidth utilization, low optical link budgets, certificate errors, license feature issues, BYOD challenges, and hardware failures. |
| **Session 28** | V257 | **Course Conclusion & Exam Tips** - Final review of exam domains and weights. Reiterates top test-taking strategies: skip simulations initially, use a brain dump sheet, manage time effectively, and take practice exams to build confidence before scheduling the real certification test. |

## Coding Standards

### File Naming

- Directories and files use `snake_case` ASCII (`[a-z0-9_.]` charset)
- No spaces, hyphens, uppercase letters, or special characters in path names
- Session notes: `session_NN_vX_vY.md` (zero-padded session number, video range)
- Diagram files: `diagram_course_*.md`
- Raw source files in `raw/`: lowercase `snake_case` (e.g., `comptia_network_resources.zip`)

### Markdown

- ATX-style headers (`#`, `##`, `###`)
- Tables use GitHub-flavored markdown pipe syntax
- Session summaries follow a consistent structure: topic introduction, key concepts, and demonstrations
