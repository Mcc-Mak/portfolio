# AGENTS.md

This repo builds an OpenCode MCP named entrepreneur-mcp (formerly 陳永仁係二五仔-內鬼-間諜-SpyFamily成員, renamed by owner decision; "the MCP"). `PROMPT-V100.2.0.md` is the authoritative spec — read the relevant section before implementing anything; it wins over prose anywhere else. The spec itself is versioned by filename (`PROMPT-V*.md`); on a version bump the old file is replaced, so always point at the highest-numbered `PROMPT-V*.md` present and never trust stale references to older versions. Historical spec versions are archived read-only under `_blueprint/`.

## Hard constraints

- **pnpm only** — never npm/yarn. Overrides npm-flavored examples in global/user-level instructions.
- ESM only: `package.json` must have `"type": "module"`; tool adapters live in `tools/*.mjs`.
- Local-first and free tooling only — no cloud/SaaS dependencies, no external AI APIs.
- TypeScript/JavaScript native. Any non-JS local CLI requires written justification in `tools/README.md`.

## Structure and phases

- Entry point: `commands/entrepreneur-mcp.md` (orchestrator + dynamic team synthesis logic). Register it, all `skills/` files, and all `tools/` adapters in `opencode.jsonc`.
- Run phases strictly 0→7 with gates between them; never advance past a failed gate.
- Everything under `skills/` (`roles-manifest.json`, `sod-matrix.md`, `tui-modules.md`, `role-<id>.md`) is **generated during Phase 0** from the user's project goal. Do not hand-write roles or SoD rules; if the goal changes, regenerate via Phase 0 instead of editing generated files.
- Use the exact `docs/` tree from the spec (`00_requirements/` … `07_reports/`) — do not invent sibling paths. Requirements SSOT: `docs/00_requirements/ssot_raw_answers.json`. TUI clarification has exactly five modules: Requirements & Business, Error/Validation, Infrastructure & SLO, Security, GDPR/SOC2.

## Gotchas

- Phase 7 report filenames are auto-versioned (`final-summary-v1.md`, `-v2.md`, …): increment the version instead of overwriting existing files.
- `README.md` is generated by the Orchestrator during Phase 7 — don't hand-maintain it earlier.
- Mandated pnpm scripts: `entrepreneur:run`, `entrepreneur:report`, `security:check`, `compliance:check`, `sbom:generate`.
