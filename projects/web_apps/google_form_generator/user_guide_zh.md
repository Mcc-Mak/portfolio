# 使用者指南：表格轉 Google 表單產生器

> 本指南適用於 `google_form_generator.gs` 中的 Google Apps Script 網頁應用程式，協助您透過貼上簡單的表格來快速建立 Google 表單。

---

## 簡介

這個工具可以幫助您快速建立 Google 表單。您不需要手動一題一題建立，只需在類似試算表的格式中準備好您的題目，一次貼上，剩下的就交給工具處理。

您還可以做這些事情：
- 新增表單標題和說明
- 設定題目為必填或選填
- 將表單儲存到特定的 Google 雲端硬碟資料夾
- 自動將回覆連結到 Google 試算表
- 匯出表單詳細資訊的 PDF 摘要（**內嵌可掃描的 QR 碼**）
- 直接從工具中刪除表單

不需要任何程式編寫知識。

---

## 開始之前

### 第一步：開啟網頁應用程式

這個工具是一個 Google 網頁應用程式。您的系統管理員會提供一個類似這樣的連結：

`https://script.google.com/macros/s/your-script-id/exec`

點擊連結即可在瀏覽器中開啟工具。

### 第二步：授予權限（僅限首次使用）

第一次開啟應用程式時，系統會要求授予以下權限：
- 建立和編輯 Google 表單
- 存取您的 Google 雲端硬碟
- 建立 Google 試算表

點擊 **審查權限**，然後點擊 **允許**。這是工具正常運作所必需的。

### 第三步：找到您的資料夾 ID

工具會將表單儲存到特定的 Google 雲端硬碟資料夾。您需要找到**資料夾 ID**：

1. 開啟 Google 雲端硬碟，找到您要儲存表單的資料夾。
2. 查看瀏覽器網址列中的網址，它會像這樣：
   `https://drive.google.com/drive/folders/your-folder-id-here`
3. 複製 `folders/` 後面那一長串字母和數字 — 這就是您的**資料夾 ID**。

> 請在輸入方框中輸入您的資料夾 ID，您隨時可以更改。

## 逐步操作說明

### 1. 設定目標資料夾

1. 在網頁應用程式中，找到標示為 **📁 目標資料夾 ID** 的方框。
2. 將您的資料夾 ID 貼入方框中。
3. 工具會檢查資料夾是否存在。您會看到確認訊息：**✅ 資料夾可存取：[資料夾名稱]**。

如果看到警告訊息，請雙重檢查您複製的資料夾 ID 是否正確。

---

### 2. 準備您的表格

工具接受**以 Tab 鍵分隔**的格式 — 您可以在 Google 試算表或 Excel 中輕鬆建立這種格式。

#### 基本題目格式（4 欄）

每個題目必須有 **4 欄**，並以 Tab 鍵分隔：

| 第 1 欄 | 第 2 欄 | 第 3 欄 | 第 4 欄 |
|---------|---------|---------|---------|
| 題目文字 | `REQUIRED` 或 `NON-REQUIRED` | 題目類型 | 說明（選填） |

#### 可使用的題目類型

| 類型名稱 | 功能說明 |
|----------|----------|
| `SHORT_ANSWER` | 單行短文字 |
| `PARAGRAPH` | 多行文字方塊 |
| `MULTIPLE_CHOICE` | 單選題（從選項中選擇一個） |
| `CHECKBOX` | 複選題（可選擇多個選項） |
| `DROPDOWN` | 下拉式選單 |
| `LINEAR_SCALE` | 線性尺度（例如 1–5 分） |
| `DATE` | 日期選擇器 |
| `TIME` | 時間選擇器 |

#### 加入選項（適用於單選題、複選題、下拉式選單）

在類型後面加上 `#` 符號，接著用逗號分隔您的選項：

```
MULTIPLE_CHOICE#是,否,不一定
```

如果是線性尺度，請使用範圍格式：

```
LINEAR_SCALE#1-5
```

#### 加入說明（第 4 欄）

第 4 欄為選填。可以用來加入輔助說明文字或指示，這些文字會顯示在題目下方。

---

### 3.（選填）加入表單中繼資料

您可以在題目之前，加入表單本身的名稱、標題和說明：

```
FORM NAME: 客戶意見調查 2024
FORM TITLE: 告訴我們您的想法
FORM DESCRIPTION START
我們重視您的意見。這份問卷大約需要 3 分鐘填寫。
您的回覆將以匿名方式處理。
FORM DESCRIPTION END
```

- **FORM NAME**：Google 雲端硬碟中的檔案名稱
- **FORM TITLE**：填答者在表單頂部看到的標題
- **FORM DESCRIPTION START** 和 **END**：讓您可以撰寫多行說明的開始與結束標記

請將這些內容放在題目的**上方**，並貼在同一個文字區域中。

---

### 4. 產生表單

1. 準備好您的表格後，將內容貼到標示為 **📊 請在此貼上您的表格** 的大文字區域中。
2. 如果您希望將回覆儲存到 Google 試算表，請勾選 **🔗 將回覆連結到 AppSheet**（建議勾選）。
3. 點擊 **產生 Google 表單** 按鈕。
4. 等待幾秒鐘。工具會顯示：
   - 成功訊息
   - 表單名稱和題目數量
   - 所有題目的預覽
   - 表單和試算表的連結
   - **內嵌的 QR 碼**（可直接掃描）

---

### 5. 檢視與分享表單

產生表單後，您會看到以下幾個連結：

| 連結 | 用途 |
|------|------|
| **編輯連結** | 開啟表單編輯器，讓您可以修改表單 |
| **回覆連結** | 前往回覆試算表（如果有勾選連結試算表） |
| **發布連結** | 分享給填答者填寫表單的連結 |
| **短網址** | 較短、較簡潔的發布連結版本 |
| **QR 碼** | 可掃描的條碼 — 其他人可以用手機相機掃描來開啟表單 |

點擊連結或按右鍵選擇**複製連結**，即可複製任何連結。

---

### 6. 刪除表單

1. 產生表單後，捲動到成功訊息的最下方。
2. 點擊紅色的 **🗑️ 刪除表單** 按鈕。
3. 在彈出視窗中點擊 **確定** 確認。
4. 表單會被移到 Google 雲端硬碟的垃圾桶。

> 此操作無法透過工具復原。您可以在 30 天內從雲端硬碟垃圾桶還原表單。

---

### 7. 匯出表單詳細資訊為 PDF

1. 產生表單後，點擊綠色的 **📄 匯出 PDF** 按鈕。
2. PDF 會自動下載到您的電腦。
3. PDF 包含以下內容：
   - 表單標題和名稱
   - 所有題目及其類型和必填狀態
   - 所有連結（編輯、發布、短網址）
   - **內嵌的 QR 碼**（可直接掃描，無需網路連線）
   - Google 雲端硬碟資料夾位置

> **💡 QR 碼特別說明**：匯出的 PDF 中的 QR 碼會以**內嵌圖片**的方式存在，不需要連網即可顯示和掃描。這與畫面上顯示的 QR 碼不同 — 畫面上的 QR 碼是即時從網路載入的，而 PDF 中的 QR 碼會直接嵌入文件內部。

這對於留存記錄或與不需要編輯權限的團隊成員分享非常有幫助。

## 範例表格（可直接複製貼上）

複製下方區塊，直接貼到工具中測試：

```
FORM NAME: 客戶意見調查
FORM TITLE: 我們重視您的意見！
FORM DESCRIPTION START
請花幾分鐘時間幫助我們改善。
所有回覆皆為匿名。
感謝您！
FORM DESCRIPTION END

請輸入您的姓名：	REQUIRED	SHORT_ANSWER	請填寫您的完整姓名
您對服務的滿意程度？	REQUIRED	LINEAR_SCALE#1-5	請從 1（非常不滿意）到 5（非常滿意）評分
您使用哪些產品？	NON-REQUIRED	CHECKBOX#產品 A,產品 B,產品 C	可複選
部門	REQUIRED	DROPDOWN#人力資源,資訊科技,業務,行銷	請選擇您所在的部門
其他建議？	NON-REQUIRED	PARAGRAPH	任何想對我們說的建議或想法
```

請完全按照上方格式貼上 — 欄位之間的空格是 **Tab 鍵**。

## 技巧與最佳作法

### ✅ 必填與選填

- 如果您希望填答者必須回答才能送出，請使用 `REQUIRED`（必須大寫）。
- 如果是選填題目，請使用 `NON-REQUIRED`。

### 📝 多行說明

要撰寫較長的表單說明，請使用：

```
FORM DESCRIPTION START
您的長篇文字內容。
可以跨越多行。
FORM DESCRIPTION END
```

### 🔧 正確設定選項格式

對於需要選項的題目類型（單選題、複選題、下拉式選單），請在逗號後不加空格：

```
CHECKBOX#紅色,綠色,藍色     ✓ 正確
CHECKBOX#紅色, 綠色, 藍色   ✗ 請避免空格
```

### 📁 保存好您的資料夾 ID

請將您的資料夾 ID 保存在安全的地方。每次使用工具時都會需要它。

### 💡 先測試再正式使用

在建立長問卷之前，先用 2–3 個題目測試，確認格式正確無誤。

## 基本疑難排解

### ❌ 「找不到有效的題目」

**發生原因：** 工具無法辨識您的表格格式。

**可以嘗試的方法：**
- 確認每個題目至少有 3 欄，並且以 Tab 鍵分隔
- 檢查 `REQUIRED` 或 `NON-REQUIRED` 是否拼寫正確且為大寫
- 移除題目之間的空行

### ❌ 「無法存取資料夾」

**發生原因：** 資料夾 ID 不正確，或者您沒有存取權限。

**可以嘗試的方法：**
- 從雲端硬碟網址中再次確認資料夾 ID
- 確認您至少擁有該資料夾的**檢視者**權限

### ❌ 選項沒有顯示在表單中

**發生原因：** 選項的格式不正確。

**可以嘗試的方法：**
- 在題目類型後面加上 `#`，然後用逗號分隔選項
- 範例：`MULTIPLE_CHOICE#是,否,不一定`
- 逗號後面請不要加上空格

### ❌ 表單建立了，但我找不到它

**發生原因：** 表單可能被儲存到錯誤的資料夾。

**可以嘗試的方法：**
- 查看成功訊息 — 它會顯示資料夾連結
- 點擊資料夾連結開啟該位置
- 下次使用時，請在產生表單前再次確認資料夾 ID

### ❌ PDF 中的 QR 碼沒有顯示

**發生原因：** 這不應該發生 — 新版工具已修復此問題。

**如果仍然遇到：**
- 確認您使用的是最新版本的 `google_form_generator.gs`
- 檢查網路連線（首次產生 QR 碼時需要連網下載圖片）
- 查看除錯主控台（畫面下方的 **📋 Debug Console**）是否有錯誤訊息
- 嘗試重新整理頁面後再產生一次表單

### 🧪 測試連線功能

如果您遇到任何問題，可以：
1. 點擊 **🧪 測試連線** 按鈕，確認工具能與伺服器正常通訊
2. 點擊 **⭐ 建立簡單測試表單** 按鈕，繞過解析邏輯直接建立一個簡單表單

這兩種方法可以幫助判斷問題是出在表格格式還是工具本身。

## 技術說明（給管理員）

### QR 碼在 PDF 中的運作方式

舊版工具使用外部圖片 URL (`https://api.qrserver.com/...`)，但 PDF 轉換器無法下載外部圖片。新版工具改為：

1. 在瀏覽器中使用 `fetch()` API 下載 QR 碼圖片
2. 使用 `FileReader().readAsDataURL()` 將圖片轉換為 Base64 編碼的資料 URL
3. 將資料 URL 內嵌到 HTML 中，再交給伺服器轉換為 PDF

這樣產生的 PDF 完全獨立，不需要連網就能顯示 QR 碼。

### 除錯主控台

畫面下方有一個 **📋 Debug Console**，會記錄：
- 頁面載入狀態
- 與伺服器的通訊內容
- 錯誤訊息

遇到問題時，可以展開主控台查看詳細日誌，有助於快速定位問題。
